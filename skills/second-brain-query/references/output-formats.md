# Output format templates

## Synthesis page template (--format page or --file-back)

```yaml
---
title: <Question or its synthesized topic>
type: synthesis
domain: <a domain listed in 00-OS/wiki/index.md>
slug: <kebab-case-slug>
created: <YYYY-MM-DD>
generated-by: second-brain-query
question: "<original user question>"
source-pages:
  - [[page-1]]
  - [[page-2]]
tags: [synthesis, query, <domain>]
---

# <Title>

## Question
<original question, verbatim>

## Answer
<synthesized markdown answer, wikilinks throughout>

## Key facts
- <fact> (source: [[page-x]])
- <fact> (source: [[page-y]])

## Contradictions surfaced
_None yet._ <or list them>

## Gaps identified
_None yet._ <or list them: "[[stub-page]] is empty", "no page for X">

## Sources (wiki pages read)
- [[page-1]]
- [[page-2]]
- …

## Sources (external, cited transitively via wiki pages)
- <pulled from frontmatter `sources:` of the wiki pages used>
```

Save as `Inbox/marp-<slug>-YYYY-MM-DD.md`.

## Chart template (matplotlib)

```python
"""Generated by /second-brain-query on YYYY-MM-DD
Question: <question>
Sources: 00-OS/wiki/<domain>/<page-1>.md, …
"""
import matplotlib.pyplot as plt

# Data extracted from wiki pages
labels = [...]
values = [...]

fig, ax = plt.subplots(figsize=(10, 6))
ax.bar(labels, values)
ax.set_title("<Question>")
ax.set_xlabel("...")
ax.set_ylabel("...")
fig.text(0.5, 0.01, "Source: 00-OS/wiki, generated YYYY-MM-DD",
         ha='center', fontsize=8, style='italic')
plt.tight_layout()
plt.savefig("chart-<slug>-YYYY-MM-DD.png", dpi=150)
```

## Canvas template (Obsidian .canvas JSON)

Nodes: one per wiki page used. Type: `file`, `file:` field points at the wiki path.
Edges: one per wikilink relationship the answer relies on. Edge labels = the
relationship (e.g., "uses", "implements", "supersedes").

See https://jsoncanvas.org/ for the schema.
